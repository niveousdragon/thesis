# Секция 2.x: Рекуррентный анализ популяционной нейронной активности (sec:v2)

## Суть

Методы снижения размерности (Гл. 2 ранее) рассматривают нейронную активность как неупорядоченное облако точек, игнорируя временную структуру. Рекуррентный анализ — единственный подход, который одновременно учитывает нелинейную динамику и темпоральные зависимости в нейронных данных.

**Что сделано:**
1. Имплементирован полный пайплайн в DRIADA 1.1 (модуль `recurrence`) — первый нейронаучный фреймворк, объединяющий все три метода из обзора Varley & Sporns 2022
2. Предложен метод популяционного графа рекуррентности (mean/thresholded JRP) — по-видимому, впервые в литературе
3. Мультиплексная сеть через Jaccard-сходство индивидуальных графов рекуррентности
4. Применение к данным NOF (кальциевый имиджинг гиппокампа) — **нужно провести**

## Элементы новизны

### 1. Популяционный граф рекуррентности (weighted/thresholded JRP)
- Классический JRP (Romano 2004) — строго бинарный AND всех подсистем
- Nomura 2022 — бинарный OR (superposed RP), только симуляции
- **Наше**: `population_recurrence_graph(method='mean')` — непрерывная [0,1] матрица (средняя доля рекуррирующих нейронов); `method='joint', threshold=0.5` — голосование большинства
- В обзоре `population_recurrence_analysis.md` прямо сказано: «has not been proposed in the literature»
- **TODO**: проверить через Google Scholar «weighted joint recurrence plot», «fractional recurrence rate»

### 2. Первый нейронаучный фреймворк для популяционного рекуррентного анализа
- Все существующие пакеты (PyRQA, CRP Toolbox, pyunicorn, RecurrenceAnalysis.jl) — одноканальные/двухканальные
- Ни один не интегрирован с нейронаучными форматами/пайплайнами
- DRIADA 1.1: per-neuron RP → population graph → Jaccard network → community detection — единый API на `MultiTimeSeries`

### 3. Три типа графов временных рядов в одном фреймворке (Varley & Sporns 2022)
- RecurrenceGraph (фазовое пространство)
- VisibilityGraph (структура экстремумов)
- OrdinalPartitionNetwork (permutation entropy)
- Все наследуют от Network → спектральный анализ, сообщества, энтропии «из коробки»
- Varley & Sporns: «there are no universal packages that will construct and analyse OPNs, RNs and VNs from provided time series data» — DRIADA это делает

### 4. Первое применение к кальциевым данным in vivo
- RQA на нейронных данных: только ISI (Kałużny 1993), MEA in vitro (Novellino 2010), ensemble labels (Pérez-Ortega 2022)
- **Никто не применял RQA к ΔF/F или деконволюции из кальциевого имиджинга**
- Никто не строил популяционные рекуррентные графы из записей отдельных нейронов

## Инструментарий DRIADA 1.1 (что реализовано)

```
driada.recurrence
├── RecurrenceGraph          — k-NN / ε-ball, Theiler window, from Network
├── compute_rqa              — DET, LAM, ENTR, TT, L, Lmax, RR, + ещё
├── estimate_tau             — TDMI (FFT-ускоренная)
├── estimate_embedding_dim   — FNN criterion
├── takens_embedding         — задержечное вложение
├── population_recurrence_graph  — joint (threshold) / mean
├── pairwise_jaccard_sparse  — мультиплексная сеть (sparse matmul)
├── VisibilityGraph          — HVG (O(N) monotone stack) / NVG
├── OrdinalPartitionNetwork  — permutation entropy
└── TimeSeries integration   — всё как cached methods
```

## Блокер: расчёты на NOF данных

Без результатов на реальных данных секция — только описание метода. Нужно:

1. **Выбрать мышь/сессию** из NOF (та же выборка, что в eff_dim / int_dim)
2. **Индивидуальные RPs**: estimate_tau, estimate_embedding_dim для каждого нейрона; RecurrenceGraph с k-NN
3. **RQA метрики** по нейронам: DET, LAM, ENTR — есть ли кластеры динамических режимов?
4. **Популяционный граф**: population_recurrence_graph (mean) — windowed RQA → динамика коллективных режимов
5. **Мультиплексная сеть**: pairwise_jaccard_sparse → сообщества → сравнить с INTENSE-селективностью
6. **Контроль**: сравнить с shuffled данными (тот же shuffle, что в eff_dim)

Ожидаемый результат: связь рекуррентных метрик с поведением (скорость, остановки) — аналогично тому, как ЭР коррелирует со скоростью в секции 2.4.
