### 3.4.1 — Постановка задачи и методы анализа представлений

**Заголовок:** `\subsection{Популяционный анализ динамики представлений}\label{sec:ib_snn}`

**Абзац 1 — связка от 3.3 (3–4 предложения):**
- В предыдущих подсекциях MEI-анализ охарактеризовал селективность отдельных нейронов SNN.
- Однако индивидуальная селективность — лишь один ракурс; за ней стоит коллективная динамика представлений в каждом слое.
- В данной подсекции те же данные активности SNN (описанной в секции \ref{sec:mango}) анализируются на популяционном уровне — с точки зрения геометрии и информационного содержания представлений.
- Все вычисления выполнены с помощью пакета DRIADA (секция \ref{sec:driada}).

**Абзац 2 — данные (3–4 предложения):**
- Исследуемая сеть — та же импульсная ResNet-18 с LIF-нейронами, описанная в секции \ref{sec:mango_methods}.
- Здесь используются суммарные spike counts (сумма бинарных спайков по T=50 временным шагам) для 10000 тестовых изображений CIFAR-10.
- Анализ проведён для всех 17 спайковых слоёв на 26 эпохах обучения (от эпохи 0 до 900), что покрывает полную траекторию обучения.
- Число нейронов в слоях варьируется от 64 (layer1) до 512 (layer4).

**Абзац 3 — меры размерности (4–5 предложений):**
- Для характеризации геометрии представлений использовались два показателя размерности, подробно описанных в секции \ref{sec:dim}:
  - Эффективная размерность (ЭР) — квадратичная энтропия Реньи спектра корреляционной матрицы с коррекцией Марченко—Пастура. Отражает число значимых линейных компонент.
  - Внутренняя размерность (ВР) — оценщик 2-NN. Отражает локальную геометрическую размерность данных на многообразии.
- Обе меры реализованы в DRIADA: `eff_dim` (модуль `dim_reduction`) и `nn_dimension` (модуль `dim_reduction`), с теми же параметрами, что в анализе кальциевых данных гиппокампа (секция \ref{sec:dim}).
- Это обеспечивает прямую сопоставимость результатов между биологической и искусственной нейронной сетью.

**Абзац 4 — оценка MI: три уровня (6–8 предложений):**
- Для количественной оценки информации о классах, содержащейся в активности каждого слоя, были использованы три уровня оценки взаимной информации I(T; Y), где T — вектор активности слоя, Y — метки классов:
  1. **Попарная MI**: $I_{ind} = \sum_i I(t_i; Y)$ — сумма точных дискретных MI отдельных нейронов с метками (contingency table). Не учитывает корреляции между нейронами; является верхней оценкой уникальной информации. (Связь с INTENSE: тот же тип оценки, что в секции \ref{sec:intense}, без пермутационного тестирования — для дискретных данных точное значение MI достаточно информативно.)
  2. **Гауссово приближение**: $I_{gauss}$ через копула-энтропию GCMI из DRIADA (модуль `information`). Учитывает попарные корреляции между нейронами. Отношение $I_{gauss}/I_{ind}$ характеризует избыточность кодирования.
  3. **Нелинейная оценка через сжатие**: автоэнкодер с дополнительной классификационной задачей (ClassificationLoss) сжимает активность слоя в 16-мерное латентное пространство Z, затем $I(Z; Y)$ оценивается непараметрическим KSG-оценщиком. Это нижняя граница на I(T; Y), контролируемая точностью классификации из Z.
- ClassificationLoss — новый компонент лосс-системы DRIADA, добавленный в модуль `dim_reduction.losses`. Автоэнкодер одновременно минимизирует ошибку реконструкции и кросс-энтропийный лосс классификации, что гарантирует сохранение классовой информации при сжатии.
- Качество сжатия контролировалось: для layer2–4 точность классификации из Z не уступает точности из полного T, подтверждая, что 16-мерное пространство не теряет существенной информации.

**Абзац 5 — information plane (2–3 предложения):**
- Информационная плоскость Тишби строится как $H_{gauss}(T)$ vs $I(Z; Y)$.
- $H_{gauss}(T) = \frac{1}{2}\sum_k \log_2(2\pi e \lambda_k)$ — гауссова верхняя граница энтропии активности слоя; для детерминированной сети $I(X; T) = H(T)$.
- Каждая точка на плоскости — один слой на одной эпохе; стрелки показывают направление обучения.

### 3.4.2 — Геометрия представлений: размерность по слоям и эпохам

**Заголовок:** `\subsection{Геометрия представлений: профили размерности}\label{sec:ib_geometry}`

**Абзац 1 — hunchback ВР по слоям (5–6 предложений):**
- Профиль ВР по слоям обученной SNN (эпоха 900) имеет характерную форму горба (hunchback): ВР растёт от первого спайкового слоя (sn1) к промежуточным слоям (layer2–3), достигая максимума, и затем падает к выходным слоям (layer4).
- Горб формируется в процессе обучения: на эпохе 5 профиль ВР практически плоский, к эпохе 100 горб уже выражен, и далее его форма стабилизируется.
- Этот паттерн согласуется с результатами Ansuini et al. (2019), впервые описавших hunchback ВР для классических ИНС (AlexNet, VGG, ResNet). Авторы интерпретировали его как переход от расширения представления (expansion) в ранних слоях к сжатию (compression) задаче-релевантной информации в поздних.
- Здесь этот результат воспроизведён для импульсной нейронной сети — насколько нам известно, впервые.
- **Рисунок** \ref{fig:ib_dim_layers}: ВР по слоям для нескольких эпох (5, 50, 100, 500, 900). Горизонтальная ось — слои (sn1 → layer4.1), вертикальная — ВР.

**Абзац 2 — ЭР не видит hunchback (3–4 предложения):**
- ЭР по слоям не показывает чёткого горба: профиль зашумлён, а последний слой (layer4.1) даёт аномальный выброс вверх.
- Это подтверждает наблюдение Ansuini et al. (2019): hunchback виден только в нелинейных мерах размерности; линейные меры (PCA, participation ratio) его не улавливают.
- Различие указывает на то, что compression в глубоких слоях происходит за счёт нелинейного «складывания» многообразия, а не сокращения числа значимых линейных компонент.
- Аналогичная ситуация наблюдалась в анализе кальциевых данных (секция \ref{sec:dim}), где ВР << ЭР << ЛР, что указывало на сильную нелинейность многообразия нейронной активности.

**Абзац 3 — V-shape ВР по эпохам (5–6 предложений):**
- При фиксированном слое ВР показывает характерную V-образную динамику по эпохам обучения: начальное падение (compression, эпохи 5–30), минимум на эпохах 20–70, и последующий рост (expansion, эпохи 40–900).
- V-shape наблюдается во всех глубоких слоях (layer3–4, 8 из 17 спайковых слоёв). В ранних слоях (layer1, sn1) ВР монотонно растёт без выраженного минимума.
- Ansuini et al. (2019) упоминали V-shape как побочное наблюдение для одного слоя (последний скрытый слой VGG-16). Здесь V-shape показан систематически для всех глубоких слоёв — это расширение их результата.
- ЭР в тех же слоях не показывает V-shape (за исключением единственного последнего слоя, где наблюдается горка: рост, затем падение). Это подтверждает, что compression/expansion — нелинейный геометрический эффект, невидимый для линейных мер.
- Переход compression → expansion не сопровождается переобучением: точность на тестовой выборке продолжает расти, что согласуется с наблюдением Ansuini et al.
- **Рисунок** \ref{fig:ib_dim_epochs}: ВР по эпохам для 4–6 репрезентативных слоёв (sn1, layer1.1, layer2.1, layer3.1, layer4.0, layer4.1). Отметить минимум для layer3–4.

**Абзац 4 — интерпретация двух фаз (3–4 предложения):**
- Двухфазная динамика (compression → expansion) допускает интерпретацию: на начальном этапе сеть сжимает многообразие активности, отбрасывая нерелевантный шум; после достижения минимума представление усложняется, формируя тонкую дифференциацию между классами.
- Это согласуется с теоретической работой Recanatesi et al. (2019), описавшей два конкурирующих механизма в глубоких сетях: expansion (рост размерности для разделения классов) и compression (снижение размерности для устойчивости к шуму).
- Для импульсных сетей LIF-нейрон реализует жёстко пороговую нелинейность (Heaviside), по логике Saxe et al. (2018), такие насыщающие нелинейности должны способствовать compression — что и наблюдается.

### 3.4.3 — Информационный анализ: information plane и избыточность

**Заголовок:** `\subsection{Информационный анализ представлений}\label{sec:ib_info}`

**Абзац 1 — I(Z;Y) по слоям: hunchback (4–5 предложений):**
- Взаимная информация между латентным представлением и метками $I(Z; Y)$ показывает по слоям профиль, аналогичный hunchback ВР: рост от sn1 (~0 бит) к layer3 (~2.3 бита), затем падение к layer4 (~1.9 бита).
- Горб $I(Z; Y)$ формируется в процессе обучения: на ранних эпохах профиль почти плоский, к эпохе 900 — выраженный.
- Совпадение форм профилей ВР и $I(Z; Y)$ — не тривиально: ВР измеряет локальную геометрию, а $I(Z; Y)$ — количество классовой информации. Их согласованность указывает на то, что слои с максимальной геометрической сложностью несут и максимум уникальной информации о классах.
- Kamkari et al. (2023) теоретически связали внутреннюю размерность и энтропию представлений. Данный результат представляет эмпирическую иллюстрацию этой связи для конкретной сети.
- **Рисунок** \ref{fig:ib_izy_layers}: $I(Z; Y)$ по слоям для нескольких эпох. Наложить на тот же набор слоёв, что и ВР (рис. \ref{fig:ib_dim_layers}), чтобы визуально сопоставить профили.

**Абзац 2 — кажущееся противоречие с DPI (3–4 предложения):**
- Рост $I(Z; Y)$ с глубиной от sn1 к layer3 может казаться противоречащим неравенству обработки данных (DPI), запрещающему рост MI в марковской цепочке.
- Однако: (a) skip connections в ResNet нарушают структуру простой цепочки — каждый блок имеет доступ к информации, минующей предыдущие слои; (b) $I(Z; Y)$ — нижняя граница, качество которой зависит от сложности данных слоя (в ранних слоях 16-мерное сжатие может быть недостаточным).
- Падение $I(Z; Y)$ от layer3 к layer4, напротив, представляет собой реальную потерю уникальной информации, согласованную с ростом избыточности (см. ниже).

**Абзац 3 — information plane (5–6 предложений):**
- На информационной плоскости ($H_{gauss}(T)$ vs $I(Z; Y)$) слои демонстрируют различные траектории в процессе обучения.
- Layer2–3: траектории направлены вправо-вверх — оба показателя растут одновременно (фаза fitting по терминологии Shwartz-Ziv и Tishby, 2017).
- Layer4: $H_{gauss}(T)$ сначала растёт, затем разворачивается влево — фаза compression. Сеть сжимает общую информацию в выходном слое, при этом удерживая $I(Z; Y)$.
- Фаза compression на information plane согласована с V-shape ВР: в layer4 минимум ВР (эп. 20–40) совпадает с началом разворота на плоскости. Два независимых метода — геометрический (ВР) и информационно-теоретический ($H_{gauss}$) — дают одну картину.
- Shwartz-Ziv и Tishby (2017) показали information plane для малых tanh-сетей. Saxe et al. (2018) показали, что compression зависит от типа нелинейности. Здесь compression наблюдается в SNN: LIF-нейроны не имеют гладкого насыщения (как tanh), но spike counts ограничены сверху ($\leq T = 50$), что ограничивает информационную ёмкость слоя сходным образом.
- **Рисунок** \ref{fig:ib_info_plane}: информационная плоскость. Стрелки показывают направление обучения (от ранних к поздним эпохам). Цвет — слой. Выделить layer4 (разворот).

**Абзац 4 — сводная таблица трёх мер (3–4 предложения + таблица):**
- Для полноты картины в таблице \ref{tab:ib_summary} сведены три меры для обученной сети (эпоха 900): ВР, $I(Z; Y)$, $H_{gauss}$.
- По слоям: ВР и $I(Z; Y)$ согласованы (hunchback, пик layer3); $H_{gauss}$ растёт монотонно (нет горба — ожидаемо, т.к. число нейронов N тоже растёт).
- По эпохам (layer4): ВР — V-shape; $H_{gauss}$ — рост → спад (compression); $I(Z; Y)$ — монотонный рост → плато.

Таблица:

| Мера | По слоям (эп. 900) | По эпохам (layer4) |
|------|--------------------|--------------------|
| ВР | hunchback: пик L3, спад L4 | V-shape: мин. эп. 20–40 |
| $I(Z;Y)$ | hunchback: пик L3, спад L4 | рост → плато |
| $H_{gauss}$ | рост с глубиной | рост → спад (compression) |

**Абзац 5 — избыточность (4–5 предложений):**
- Сумма попарных MI отдельных нейронов $I_{ind} = \sum_i I(t_i; Y)$ многократно превышает $I(Z; Y)$ во всех слоях и на всех эпохах.
- В layer4 при эпохе 900 $I_{ind}$ достигает 300+ бит, тогда как $I(Z; Y) \approx 1.9$ бита, $H(Y) = \log_2 10 \approx 3.32$ бита. Нейроны выходного слоя массово дублируют классовую информацию.
- Отношение $I_{gauss}/I_{ind} < 1$ повсюду, что указывает на преобладание избыточного (redundant) кодирования.
- Максимальная избыточность — в layer4, где сеть, по-видимому, формирует устойчивое к шуму, но информационно избыточное представление для принятия решения о классе.
- Следует отметить, что $I_{gauss}$ нестабилен в layer4 (N = 512 нейронов, плохая обусловленность ковариационной матрицы), поэтому количественные значения отношения в этих слоях следует интерпретировать с осторожностью.

**Абзац 6 — контроль latent_dim (3 предложения):**
- Для проверки устойчивости результатов анализ $I(Z; Y)$ был повторён с latent_dim = 8 (вместо 16). Hunchback $I(Z; Y)$ по слоям сохраняется: пик в layer3 (2.57 vs 2.29 при dim=16), падение к layer4 (2.42 vs 1.89).
- Compression на information plane (разворот стрелок в layer4) также воспроизводится. Количественные значения зависят от размерности сжатия, но качественная картина устойчива.

### 3.4.4 — Связь популяционной динамики и индивидуальных специализаций

**Заголовок:** `\subsection{Связь динамики представлений с индивидуальными специализациями нейронов}\label{sec:ib_mei}`

**Абзац 1 — зачем: мотивация связки (3 предложения):**
- Описанные выше результаты характеризуют динамику представлений на уровне слоёв целиком. Результаты секции \ref{sec:mango_results}, напротив, описывают эволюцию селективности отдельных нейронов через их MEI.
- Доступность обоих типов данных для одной и той же сети позволяет исследовать, как популяционные фазы (compression, expansion) связаны с формированием индивидуальных специализаций.

**Абзац 2 — compression предшествует специализации (5–6 предложений + таблица):**
- В слоях с V-shape ВР (layer3–4) минимум размерности систематически наступает раньше, чем появление устойчивой MEI-селективности (по критерию из секции \ref{sec:mango_selectivity}).
- Таблица \ref{tab:ib_compression_vs_spec}:

| Слой | Мин. ВР (эпоха) | Появление селективности (эпоха) | Разрыв (эпохи) |
|------|-----------------|----------------------------------|-----------------|
| layer3.1 | 70 | 150 | 80 |
| layer4.0 | 50 | 60 | 10 |
| layer4.1 | 20 | 40 | 20 |

- Интерпретация: сеть сначала сжимает представление (phase compression), и лишь затем на сжатом многообразии нейроны формируют устойчивые class-specific специализации.
- Наибольший разрыв — в layer3.1, что согласуется с аномалией MEI-активаций в этом слое, отмеченной в секции \ref{sec:mango_selectivity}: слой с максимальной информационной нагрузкой (max $I(Z; Y)$, max ВР) перестраивает представления дольше всего.
- Обратить внимание: разрыв зависит от выбора критерия селективности (порог уверенности, стабильность по запускам); при смягчении критерия он сокращается. Тем не менее порядок (сначала compression, затем селективность) устойчив.

**Абзац 3 — per-neuron MI предсказывает MEI-специфичность (5–6 предложений):**
- Для каждого нейрона (576 нейронов: 9 слоёв × 64) на эпохе 700 была вычислена точная дискретная MI с метками $I(t_i; Y)$ и сопоставлена со специфичностью его MEI (relative perplexity: 1.0 — неуверенный, близок к 0 — уверенный в одном классе).
- Корреляция усиливается с глубиной: от r ≈ 0 в ранних слоях (sn1, layer1) до r = −0.75 в layer4.1. Нейроны с высокой MI имеют более class-specific MEI.
- Этот результат связывает информационно-теоретический и генеративный подходы к анализу селективности: статистическая зависимость нейрона от меток (MI) предсказывает, насколько его оптимальный стимул (MEI) принадлежит конкретному классу.

**Абзац 4 — аномалия L3.1 (3–4 предложения):**
- Layer3.1 выделяется: средняя $I(t_i; Y)$ максимальна среди всех слоёв (0.58 бит), но корреляция MI с MEI-специфичностью практически нулевая (r ≈ 0).
- Все нейроны этого слоя высоко информативны в отношении класса, но их MEI не дифференцированы по классам. Это согласуется с ролью layer3 как «информационного горлышка» (max $I(Z; Y)$, max ВР): слой кодирует максимум классовой информации распределённо, без выраженной индивидуальной class-специфичности.
- На уровне слоя (средние по эпохам) корреляция $I(Z; Y)$ с MEI perplexity составляет r = −0.61, подтверждая связь макро- и микро-уровня.

**Абзац 5 — INTENSE как валидация (2–3 предложения, БЕЗ отдельной подсекции):**
- Метод INTENSE (секция \ref{sec:intense}) был применён к spike counts SNN без модификации алгоритма. Корреляция с точной дискретной MI составила r > 0.97, что подтверждает корректность оценщика GCMI на дискретных данных.
- При 10000 сэмплов и 10 классах подавляющее большинство нейронов оказывается статистически значимым (>95% во всех слоях), что отражает высокую мощность теста при большом объёме данных, а не содержательную избирательность.

### 3.4.5 — Обсуждение результатов популяционного анализа

**Заголовок:** `\subsection{Обсуждение}\label{sec:ib_discussion}`

**Абзац 1 — три масштаба (4–5 предложений):**
- Проведённый анализ объединяет три масштаба описания одной сети: макро (information plane, общая/классовая MI), мезо (геометрия представлений: ВР, ЭР, избыточность) и микро (MEI отдельных нейронов).
- Согласованность результатов между масштабами — hunchback одновременно в ВР и $I(Z; Y)$, V-shape ВР и compression на information plane, корреляция per-neuron MI с MEI — подтверждает, что наблюдаемые паттерны отражают реальную структуру обучения, а не артефакты отдельных методов.
- Такой мультимасштабный анализ стал возможен благодаря сочетанию трёх инструментов: MANGO (генерация MEI, секция \ref{sec:mango}), INTENSE (статистическая оценка селективности, секция \ref{sec:intense}) и DRIADA (размерность, MI, автоэнкодеры, секция \ref{sec:driada}).

**Абзац 2 — DRIADA как инструмент (3–4 предложения):**
- Все вычисления в данной секции выполнены через API пакета DRIADA: `eff_dim` и `nn_dimension` (размерность), `mi_model_gd` (GCMI), `compute_me_stats` (INTENSE), `ModularAutoencoder` с `ClassificationLoss` (сжатие + KSG).
- ClassificationLoss, разработанный для задач данной секции, был интегрирован в лосс-систему DRIADA и доступен для применения к другим данным.
- Использование единого API обеспечивает воспроизводимость и согласованность между разными видами анализа.

**Абзац 3 — параллель с Главой 2 (3–4 предложения):**
- Методы ЭР и ВР, применённые к активности SNN, — те же, что использовались в анализе кальциевой активности нейронов гиппокампа (секция \ref{sec:dim}).
- В обоих случаях ВР оказалась существенно ниже ЭР, что указывает на нелинейную структуру многообразия; в обоих случаях линейные меры не улавливали эффекты, видимые через ВР.
- Это демонстрирует, что инструментарий, разработанный для анализа биологических нейронных данных, содержательно применим к данным искусственных нейронных сетей — и наоборот.

**Абзац 4 — ограничения (4–5 предложений):**
- Результаты получены для одной архитектуры (ResNet-18) на одной задаче (CIFAR-10). Обобщение на другие архитектуры SNN и задачи требует дополнительных экспериментов.
- $I_{gauss}$ нестабилен в слоях с большим числом нейронов (N = 512, layer4) из-за плохой обусловленности ковариационной матрицы; количественные значения в этих слоях следует интерпретировать с осторожностью.
- Оценка $I(Z; Y)$ через автоэнкодер даёт нижнюю границу, качество которой зависит от размерности сжатия и обучения AE. Контроль с dim = 8 показал устойчивость качественных результатов, но точные значения варьируются.
- Контроль с обучением на случайных метках (random labels) не был проведён из-за вычислительной стоимости переобучения SNN и оставлен для дальнейших исследований.

## Нарративная функция секции 3.4

```
3.1 INTENSE (инд. селективность)
    ↓ «что видит каждый нейрон» (MI)
3.2 DRIADA (инструментарий)
    ↓ API для всех масштабов
3.3 MANGO (генерация MEI)
    ↓ «какой стимул максимально активирует»
3.4 Популяционный анализ SNN ← ВСЁ СХОДИТСЯ
    - DRIADA: ЭР, ВР, MI, AE → размерность + information plane
    - INTENSE: валидация per-neuron MI на SNN
    - MANGO: MEI-селективность ↔ compression
    → Три инструмента × три масштаба × одна сеть
```
