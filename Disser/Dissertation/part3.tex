Методы анализа индивидуальной нейронной селективности (секция~\ref{sec:intense}) и коллективной популяционной динамики (секции~\ref{sec:geometry}--\ref{sec:snn_population}), описанные в данной работе, на практике применяются к одним и тем же экспериментальным записям и тесно связаны друг с другом. Селективные свойства отдельных нейронов определяют геометрию популяционного многообразия, а коллективные переменные, извлечённые из популяционной активности, позволяют переосмыслить роль каждого нейрона в контексте всей популяции. Тем не менее существующие программные пакеты, как правило, работают лишь на одном из этих масштабов. Среди информационно-теоретических инструментов выделяются NIT~\cite{Maffulli2024}, предоставляющий оценки взаимной информации с коррекцией смещения, и MINT~\cite{Lorenz2025}, работающий на уровне популяции, но не отдельных нейронов. На популяционном уровне CEBRA~\cite{Schneider2023} строит устойчивые вложения, а dPCA~\cite{Kobak2016} раскладывает активность по задачным переменным, однако оба не предоставляют статистического тестирования индивидуальной селективности. Пакет FRITES~\cite{Combrisson2022} ориентирован на анализ функциональной связности в данных ЭЭГ и МЭГ. Фреймворк SIMNETS~\cite{SIMNETS2025} строит карты функционального сходства нейронов по их спайковым паттернам и выделяет подсети со схожими вычислительными свойствами, однако не оценивает селективность нейронов к внешним переменным. Ни один из этих инструментов не объединяет все три масштаба анализа~--- индивидуальный, популяционный и сетевой~--- в рамках единой программной среды. Для решения этой задачи был разработан программный пакет DRIADA (\textit{Dimensionality Reduction for Integrated Activity Data})~--- открытый фреймворк на языке Python, объединяющий инструменты анализа нейронной активности на всех трёх масштабах. Пакет распространяется под лицензией MIT и доступен для установки из репозитория PyPI.

\subsection{Архитектура пакета DRIADA}

Центральным элементом архитектуры DRIADA является единая модель данных: объект эксперимента хранит матрицу нейронной активности размера $N \times T$ (где $N$~--- число нейронов, $T$~--- число временных кадров), набор синхронизированных по времени поведенческих и средовых переменных, а также метаданные каждого нейрона. При загрузке данных пакет автоматически определяет тип каждой переменной~--- непрерывная, дискретная, циклическая или многокомпонентная~--- и сохраняет предвычисленные представления (копула-преобразования, дискретизированные значения, границы допустимых временных сдвигов), необходимые для последующего анализа. Благодаря этому все модули работают с единым объектом данных без повторного форматирования.

% \future{Рисунок: блок-схема архитектуры DRIADA (модули и потоки данных)}  % рабочий маркер скрыт

На основе единой модели данных организовано пять модулей анализа:

\begin{enumerate}
    \item \textit{Анализ селективности} (\texttt{intense})~--- статистическое тестирование связей между активностью нейронов и внешними переменными на основе взаимной информации. Методы оценки и статистического тестирования подробно описаны в секции~\ref{sec:intense}.
    \item \textit{Снижение размерности} (\texttt{dim\_reduction})~--- извлечение коллективных переменных из популяционной активности с помощью 15~методов, включая линейные (PCA), графовые (Isomap, диффузионные карты, лапласовы собственные карты, UMAP) и нейросетевые (автоэнкодеры), а также оценка внутренней размерности данных несколькими способами.
    \item \textit{Сетевой анализ} (\texttt{network})~--- построение и анализ функциональных нейронных сетей: спектральное разложение, выявление сообществ, расчёт графовых энтропий.
    \item \textit{Анализ репрезентационного сходства} (\texttt{rsa})~--- построение матриц несходства репрезентаций, сравнение нейронных представлений между областями мозга, экспериментальными сессиями и условиями.
    \item \textit{Интеграция масштабов} (\texttt{integration})~--- связывание индивидуального и популяционного уровней: определение вклада отдельных нейронов в компоненты популяционного многообразия, количественная оценка индивидуального вклада в коллективную геометрию методом последовательного исключения.
\end{enumerate}

Важной особенностью реализации является ускоренное пермутационное тестирование на основе циклических временных сдвигов с применением быстрого преобразования Фурье, подробно описанное в секции~\ref{sec:intense_stat}. Оценщик GCMI~\cite{Ince2017} используется по умолчанию благодаря аналитической форме, совместимой с данным конвейером, тогда как оценщик KSG~\cite{Kraskov2004} доступен для обнаружения произвольных нелинейных зависимостей за счёт более высокой вычислительной стоимости.

Ключевой особенностью архитектуры является бесшовная связь между модулями, обеспечиваемая единой моделью данных. Графовые методы снижения размерности возвращают графы близости, к которым непосредственно применим весь инструментарий модуля сетевого анализа: популяционная структура, извлечённая при обучении многообразия, может быть исследована как функциональная сеть без дополнительных преобразований данных. Один и тот же статистический аппарат на основе взаимной информации лежит в основе анализа связей <<нейрон--переменная>>, <<нейрон--нейрон>> и <<переменная--переменная>>, обеспечивая единообразие статистических выводов на разных масштабах.

Архитектура пакета не привязана к конкретному типу нейронных данных. Помимо записей кальциевого имиджинга, для которых пакет первоначально разрабатывался, DRIADA поддерживает электрофизиологические данные и активации искусственных нейронных сетей. Субстратная универсальность пакета была продемонстрирована в работе~\cite{Kononov2025}, где DRIADA использовалась для анализа скрытых состояний рекуррентной нейронной сети, обученной методом обучения с подкреплением.

\subsection{Применение DRIADA в задачах данной работы}

Пакет DRIADA использовался для получения результатов, представленных в нескольких разделах данной диссертации:

\begin{enumerate}
    \item \textit{Снижение размерности и извлечение коллективных переменных}~--- классическими, графовыми и нейросетевыми методами (секции~\ref{sec:geometry},~\ref{sec:v2},~\ref{sec:rnn},~\ref{sec:snn_population}).
    \item \textit{Обработка нейронных временных рядов}~--- общие инструменты (расчёт энтропии, вложение Такенса, графы рекуррентности, оценка времени автокорреляции) и специфичные для кальциевого имиджинга (выделение кальциевых событий из сырого сигнала, вейвлетное удаление шума).
    \item \textit{Оценка эффективной и внутренней размерности} популяционной нейронной активности несколькими методами (секции~\ref{sec:dim},~\ref{sec:snn_population}).
    \item \textit{Анализ индивидуальной нейронной селективности} с помощью INTENSE (секции~\ref{sec:intense},~\ref{sec:rnn}).
    \item \textit{Анализ вовлечённости отдельных нейронов в популяционный код} (секция~\ref{sec:popcode})~--- оценка связи активности отдельных нейронов с коллективными переменными средствами модуля интеграции масштабов.
\end{enumerate}

Таким образом, DRIADA обеспечивает единую программную среду для всех вычислительных экспериментов данной работы, гарантируя согласованность форматов данных, статистических процедур и промежуточных результатов между различными видами анализа.
